# 债券一级市场看板 · 内网部署说明

> 本包为**完整可运行版**：已包含构建产物（`.next`）与依赖（`node_modules`），
> 同事只需一台装好 Node.js 的 Windows 机器即可直接启动，无需联网 `npm install` 或 `next build`。

---

## 一、环境要求

- **Windows**（建议 Win10/11）
- **Node.js ≥ 18**（启动时从系统 PATH 解析 `node`，请先装好并确保 `node -v` 可用）

## 二、部署步骤

1. 把整个 `bond-dashboard` 文件夹拷贝到内网机器任意路径（例如 `D:\bond-dashboard`）。
2. 配置凭证：
   - 复制 `.env.local.example` 为 `.env.local`；
   - 填入你的 DM 数据源凭证（`INNO_APP_KEY` / `INNO_APP_SECRET`），
     以及可选的 `WECHAT_WEBHOOK`。
3. 启动服务（二选一）：
   - **双击运行** `start.ps1`，或命令行执行
     `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1`
   - 或直接运行 `node scripts\serve.mjs`
4. 浏览器访问：`http://<本机IP>:3000`（本机访问 `http://localhost:3000`）。

## 三、开机自启（可选）

用 Windows 任务计划程序新建一个「登录时」触发的任务，操作指向：

```
powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "D:\bond-dashboard\start.ps1"
```

`start.ps1` 已内置「端口 3000 已监听则自动跳过」，重复触发安全。

## 四、注意事项

1. **数据更新**：配置 `.env.local` 的 DM 凭证后，服务器**每晚 19:00 自动刷新**（日历补数、参与/中标记录缴款日/上市日回填、个券估值、30Y 国债、发行人评级、票面曲线——见 `方案B改造说明.md` 第五节），也可在「数据管理」面板手动触发。仅「历史趋势 / 发行人YTD / 组合序列」仍为打包快照，需同事机器管道同步；`scripts/daily_refresh.py` 等脚本依赖打包者本机数据源，本机无需运行。
2. **Excel 上传功能已剔除**：本包不含 Excel 导入相关模块（`src/app/api/excel`、`excel-import-button` 等），因为该功能依赖打包者的本机 Excel 文件与路径。
3. **本机硬编码路径**：`start-bond-dashboard.ps1` / `start-bond-dashboard.bat`（旧启动脚本）仍硬编码了打包者机器的绝对路径，**请勿使用**，改用本包的 `start.ps1`。
4. 端口默认 **3000**；如需修改，编辑 `scripts/serve.mjs` 中的 `PORT`。

## 五、目录结构

```
bond-dashboard/
├── .next/                 # 构建产物
├── node_modules/          # 依赖
├── data/                  # 数据 JSON（发行/估值/评级缓存等）
├── public/                # 静态资源
├── src/                   # 源码（含 Next.js App Router 页面与 API）
├── scripts/
│   ├── serve.mjs          # 分离式启动器（核心）
│   └── *.py               # 数据刷新脚本（需 Python + 数据源）
├── start.ps1              # 通用启动脚本（部署版，推荐用这个）
├── .env.local.example     # 凭证模板
└── package.json
```
